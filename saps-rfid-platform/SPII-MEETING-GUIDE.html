3 How Zebra Readers Connect

Say This
"Zebra readers speak a protocol called LLRP - Low Level Reader Protocol. Our system connects to each reader over TCP/IP on port 5084. When a reader sees a tag, it sends us a message with the tag ID and signal strength. We process that in under 50 milliseconds and update the 3D view."
LLRP - Low Level Reader Protocol

Industry standard protocol - works with ALL major RFID readers

DATA FLOW: Tag Detection to 3D Update
1
📡 Tag Detected
RFID tag passes near Zebra reader antenna. Radio waves bounce off tag and return unique identifier.
EPC: E200-3412-8765-0001 | RSSI: -45dBm | Antenna: 2
2
📨 LLRP Message Sent
Zebra reader packages tag data into RO_ACCESS_REPORT message and sends over TCP to our server.
Message Type: RO_ACCESS_REPORT | Protocol: LLRP | Port: 5084
3
⚙️ Gateway Processes
Our LLRP Gateway parses the message, extracts tag data, deduplicates (filters repeated reads), and maps EPC to item in database.
LLRPGateway.ts → TagProcessor.ts → TagDeduplicator.ts
4
📍 Location Calculated
Based on which reader saw it, which antenna, and signal strength (RSSI), we calculate the item's 3D position in the warehouse.
Reader Position + Antenna Direction + RSSI = 3D Coordinates (x, y, z)
5
💾 Database Updated
Item's location is saved to TimescaleDB (time-series database optimized for sensor data).
PostgreSQL + TimescaleDB | Location history preserved
6
🧠 AI Checks Patterns
AI engine checks if this movement is normal. Triggers alert if: too long in one place, unauthorized zone, unusual sequence, after hours.
Dwell Time | Zone Rules | Movement Patterns | Time Rules
7
⚡ WebSocket Broadcast
Socket.IO sends real-time update to all connected browser clients.
Event: item:moved | Payload: { itemId, newPosition, zone }
8
🎮 3D View Updates
React Three Fiber receives update and smoothly animates the item to its new position in the 3D warehouse model.
Three.js | 60 FPS | Smooth animation

4 Zebra Hardware Integration

Say This
"We support all Zebra LLRP-compatible readers. For fixed installations we use FX7500 readers with AN720 antennas. For mobile scanning, RFD40 handhelds. For tagging items, ZT411 RFID printers. All these connect to our software through standard protocols."
📻
Fixed Reader
Zebra FX7500 / FX9600
Mounted on walls, doors, ceilings. Reads tags automatically as items pass by. Connects 4 antennas.
Connection: Ethernet → TCP Port 5084 → LLRP Protocol
📡
Antenna
Zebra AN720
Circular polarized antenna. 6dBi gain. Reads tags up to 9 meters away. Each reader supports 4 antennas.
Connection: Coax cable → FX7500 antenna port
📱
Handheld Sled
Zebra RFD40 Premium Plus
Attaches to smartphone. Mobile inventory counts. Find specific items. Works offline, syncs later.
Connection: Bluetooth → Phone App → REST API
🖨️
RFID Printer
Zebra ZT411 RFID
Prints labels AND encodes RFID tags in one step. Each tag gets unique EPC code linked to item in database.
Connection: USB/Ethernet → Print API → Encodes EPC

8 Common Questions & Answers

Q: How is this different from existing solutions?
"Zebra and Impinj sell hardware - their software shows tables. We're software-first with 3D visualization. No one in South Africa does this."
Q: Can it work with readers we already have?
"Yes - any LLRP-compatible reader works. That's an open industry standard. We're not locked to Zebra specifically."
Q: How do you know WHERE an item is?
"Each reader has a known position. Signal strength tells us distance. Multiple readers triangulate. The item appears at that calculated position in 3D."
Q: How fast is it?
"Tag read to 3D update: under 50 milliseconds. Camera fly-to: under 1 second. The frontend runs at 60 FPS with 250+ items."
Q: What if a reader goes offline?
"Automatic reconnection with exponential backoff. Circuit breaker pattern prevents cascading failures. Health monitoring alerts you immediately."
Q: What's the funding for?
"Software is complete. We need hardware - Zebra readers, antennas, handhelds - to deploy at two pilot sites and prove it works in production."
